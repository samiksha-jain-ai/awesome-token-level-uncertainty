# GitHub Implementations

This collection contains open-source implementations related to hallucination detection, uncertainty quantification, semantic uncertainty, and token-level analysis of Large Language Models.

---

## 1. HaDeS — Token-Level Reference-Free Hallucination Detection

**Repository:** Microsoft Research

**Description:**
HaDeS provides the implementation and dataset for token-level, reference-free hallucination detection in free-form text generation. The repository includes data, baseline implementations, and instructions for reproducing experiments.

**Why it is relevant:**
This is one of the most directly relevant implementations for this repository because it focuses specifically on hallucination detection at the token level.

**GitHub:**
https://github.com/microsoft/HaDes

**Note:**
The repository is currently archived/read-only, but it remains useful as a research implementation and reproducibility reference.

---

## 2. SelfCheckGPT

**Repository:** Potsawee Manakul

**Description:**
SelfCheckGPT implements several approaches for detecting hallucinations without requiring access to model probabilities. It includes BERTScore, question-answering, n-gram, NLI, and LLM-prompting approaches.

**Why it is relevant:**
SelfCheckGPT provides an important comparison with uncertainty-based methods. It detects potential hallucinations by checking the consistency of multiple responses generated by the same model.

**GitHub:**
https://github.com/potsawee/selfcheckgpt

---

## 3. UQLM — Uncertainty Quantification for Language Models

**Repository:** CVS Health

**Description:**
UQLM is a Python library for LLM hallucination detection using uncertainty quantification techniques. It includes black-box and white-box uncertainty scorers.

**Why it is relevant:**
UQLM is directly connected to the central topic of this repository because it uses uncertainty signals to estimate the reliability of LLM outputs. Its white-box methods can use token probabilities when those probabilities are available.

**GitHub:**
https://github.com/cvs-health/uqlm

---

## 4. SIRIN — Semantic Inconsistency Recognition and Inspection Nexus

**Repository:** SB-AI-Lab

**Description:**
SIRIN is a Python library for detecting and analyzing contextual inconsistencies in systems using LLMs. It supports hallucination detection and query-answerability detection.

**Why it is relevant:**
SIRIN is particularly relevant because it supports both sequence-level and token-level detection and includes uncertainty-quantification approaches. It provides token-level uncertainty feature processing for hallucination detection.

**GitHub:**
https://github.com/sb-ai-lab/SIRIN

---

## 5. Semantic Entropy Reproduction Code

**Repository:** Lorenz Kuhn / Research Code

**Description:**
This repository contains code used to reproduce experiments from the research on detecting hallucinations using semantic entropy.

**Why it is relevant:**
Semantic entropy provides an important alternative to simple token-level uncertainty by measuring uncertainty over the meaning of generated responses. The implementation is therefore useful for comparing token-level and semantic-level uncertainty methods.

**GitHub:**
https://github.com/jlko/long_hallucinations

# Why These Implementations Matter

The selected repositories represent different approaches to hallucination detection:

### Token-level approaches

HaDeS and SIRIN provide fine-grained methods that can identify unreliable content at the token level.

### Probability-based uncertainty

UQLM provides uncertainty-based methods, including approaches that can make use of token probabilities from language models.

### Self-consistency

SelfCheckGPT identifies potential hallucinations by comparing multiple outputs generated from the same model.

### Semantic uncertainty

The semantic entropy implementation investigates uncertainty over meanings rather than simply individual tokens.

Together, these implementations provide a useful comparison of different approaches for studying the relationship between uncertainty and hallucination in LLMs.

---

# Selection Criteria

Repositories were selected based on their direct connection to hallucination detection or uncertainty estimation, availability of implementation code, relevance to the research topic, and usefulness for reproducing or understanding research methods.

The repositories include both token-level and broader uncertainty-based approaches so that different levels of hallucination detection can be compared.
